# OurShed — Grow Together

A clean, responsive concept website for **OurShed**, a small-space gardening kit business project aligned with UN Sustainable Development Goal 9.

## Website

- `index.html` — homepage, GrowBox modular concept, product collection, target prices, how-it-works, guides, and Garden Helper.
- `donate.html` — dedicated Grow Together donation/impact page explaining proposed use of contributions, accountability, and current program status.
- `assets/planter-box.jpg` — illustrative planter photo, not a validated GrowBox product photograph.

This is a **static website**: no Node.js, build step, Lovable, or npm is required. To preview, open `index.html` in a browser. To publish, deploy the repository as a static site with its publish directory set to the repository root (`.`).

## Product concepts

- GrowBox Starter — proposed $44.99
- GrowBox extension — proposed $19.99
- Two-section GrowBox bundle — proposed $59.99
- Window Herb Kit — proposed $24.99
- Patio Planter Kit — proposed $34.99
- Seed Starter Kit — proposed $14.99

**All products, modular connections, prices, dimensions, and assembly claims are proposals requiring prototype testing.** There is no active checkout.

## Community initiative

The planned Grow Together initiative proposes funding one basic community gardening kit for every ten GrowBox kits sold. No donation processing is active, and no verified partnerships or deliveries are claimed. The donation page is informational until the program is established.
